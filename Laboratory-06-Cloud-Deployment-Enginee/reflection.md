# Mission Reflection

During this mission, I learned how Docker Compose simplifies the process of deploying applications in a cloud environment.

Writing a `docker-compose.yml` file makes a cloud engineer's work easier because all the required services and configurations are organized in one file. Instead of manually entering several Docker commands, the engineer can start the application and its dependencies using a single command. This also makes deployment more consistent and easier to repeat.

I also learned that YAML files require proper indentation. If I use a Tab instead of spaces or place a line at the wrong indentation level, the configuration may produce an error or fail to work correctly. This taught me to carefully check the formatting of my configuration files.

Environment variables, such as `MYSQL_PASSWORD`, allow the application and database to receive the settings they need. They help separate configuration values from the application itself, making the setup easier to manage. However, passwords should be protected and should not be exposed in public repositories.

Deploying Nextcloud in just a few minutes felt exciting and rewarding. It showed me that a cloud storage system can be set up efficiently with the help of containerization. Although some errors can occur during deployment, troubleshooting them helped me understand the process better.

Since Mission 1, my understanding of cloud computing has improved. I now understand that cloud computing involves more than storing files online. It also includes deploying applications, managing containers, configuring networks, connecting databases, and maintaining services. I learned that automation and proper documentation are important skills for cloud engineers because they make systems easier to deploy, manage, and maintain.

Overall, this mission improved my technical knowledge and gave me more confidence in using Docker and Docker Compose. It also helped me appreciate how modern tools make application deployment faster, more organized, and more reliable.
