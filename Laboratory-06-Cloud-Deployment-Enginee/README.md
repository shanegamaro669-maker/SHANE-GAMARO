# Laboratory 06 – Cloud Deployment Engineer

## Mission Overview

This mission focused on deploying Nextcloud using Docker Compose. It demonstrated how containers and a database work together to provide a cloud storage application.

## Objectives

* Understand Docker Compose configuration.
* Deploy Nextcloud and its database.
* Connect application and database containers.
* Document deployment commands and configurations.

## Commands Executed

* `mkdir nextcloud-deployment` – Creates the project directory.
* `cd nextcloud-deployment` – Opens the project directory.
* `docker compose up -d` – Starts the services in the background.
* `docker ps` – Displays running containers.

## Skills Learned

* Writing and understanding YAML files.
* Deploying applications with Docker Compose.
* Connecting containers through service names.
* Using environment variables.
* Troubleshooting deployment errors.
