
# Mission Reflection

## 1. Which cloud infrastructure component do you think is the most important? Why?

I think **compute resources** are the most important cloud infrastructure component because they provide the processing power needed to run applications and services. Without CPU and memory resources, other components such as storage and networking would not be able to support active workloads effectively. Compute resources also allow organizations to scale their applications based on demand.

## 2. How does Linux support cloud computing?

Linux supports cloud computing by providing a reliable and flexible operating system for servers and virtual machines. It includes powerful command-line tools for managing CPU, memory, storage, networking, users, and processes. Linux is also widely used in cloud environments because it is efficient, customizable, and supports many modern cloud technologies.

## 3. Why is technical documentation important before deploying infrastructure?

Technical documentation is important because it provides a clear record of the infrastructure design, configuration, and requirements. It helps engineers understand what resources are needed and reduces the possibility of configuration errors. Good documentation also makes troubleshooting, maintenance, collaboration, and future infrastructure changes easier.
